# 트랜스포머 도감 (TRANSFORMERS ARCHIVE)

사이버트론에서 온 오토봇 12명과 디셉티콘 10명, 모두 22명의 트랜스포머를 한눈에 보는 어린이용 도감 웹앱입니다.
초등 저학년 아이가 갤럭시탭의 삼성 인터넷에서 앱처럼 설치해 쓰도록 만들었습니다.

- 주소: https://yuuunjk.github.io/transformers/
- 수록 오토봇(12): 옵티머스 프라임 · 범블비 · 아이언하이드 · 라쳇 · 재즈 · 휠잭 · 알시 · 프롤 · 그림록 · 울트라 매그너스 · 하운드 · 미라지
- 수록 디셉티콘(10): 메가트론 · 스타스크림 · 사운드웨이브 · 쇼크웨이브 · 바리케이드 · 블랙아웃 · 록다운 · 브롤 · 스컬지 · 나이트버드
- 기능: 진영 폴더 탭(전체·오토봇·디셉티콘·🎮 미니게임) + 그 아래 사이버트론 아카이브 패널의 역할 필터(역할 전체·지휘관·항공·정찰·전투·과학·첩보·의무·발명·다이노봇), 이름·변신 기종·작품 검색, ⭐ 내 최애(localStorage), 낮/밤 화면
- 프로필: 역할·소속 부대·변신 기종(실제 기종명)·신장·상징 컬러·주무장·특수 장비·첫 등장 작품
- 🔒 루틴 기록 연동 잠금: 트랜스포머 앱이 같은 도메인(`yuuunjk.github.io`)의 루틴 앱 저장소를 직접 읽어 오늘 미니게임을 열지 정합니다. 읽는 값은 `localStorage['lukaPokemonDashboard.v1']`의 `days['YYYY-M-D']`(0 패딩 없는 날짜 키) 이고, 모드는 `day.mode || state.mode || 'school'`, 오후 루틴이 있는 모드(`school`·`afterschool`)는 `slots[mode+':after']`, 없는 모드(`holiday`·`vacation`)는 `slots[mode+':morning']`을 봅니다. 그 슬롯의 `tasks`가 전부 true이거나 `claimed === true`, 또는 `rewarded.after`/`rewarded.morning`이면 완료로 봅니다. 완료 기록이 없으면 잠금 안내만 보여 줍니다(부모 비번 없음).
- ⏰ 미니게임은 매일 20:30까지: 20:30이 넘으면 네 가지 게임 모두 잠기고 `미니게임은 오후 8시 30분까지만 열려요! 내일 다시 해 봐요` 안내가 나옵니다(자정이 지나면 잠금은 날짜 기준으로 다시 계산).
- 🔒 오후 루틴 연동: 오늘 오후 루틴을 끝내기 전에는 미니게임이 잠깁니다. 루틴 대시보드가 여는 `?from=routine&day=YYYY-MM-DD&tab=minigame` 링크(오늘 날짜일 때) 또는 같은 origin의 루틴 앱 저장소(`lukaPokemonDashboard.v1`의 `*:after` 슬롯 전부 완료)로 그날 하루 잠금이 풀리고, 자정이 지나면 다시 잠깁니다. 잠금 화면에는 `루틴 앱 열기` 버튼만 둡니다(부모 비번 없음).
- 🎮 미니게임 탭: ① 1:1 VS 대결(5가지 능력치 좌우 막대·총점·우세 항목·예상, 하루 2회) ② 키·크기 줄세우기(22명 신장 순, 진영 필터, 무제한) ③ 누구일까? 퀴즈(변신 차종·특징·활약 힌트 + 4지선다, 점수·뱃지 없이 정답·해설, 하루 3문제) ④ 내 최애 3인 팀(3명 선택 → 팀 평균 능력치·시너지, 하루 1팀). 횟수는 localStorage에 그날 날짜로 저장하고 날짜가 바뀌면 자동 초기화됩니다.
- 관계: 최고의 콤비 / 라이벌(도감에 있는 이름을 누르면 그 캐릭터 프로필로 바로 이동), 전투 스타일과 능력치 5종(힘·스피드·지능·용기·화력)과 종합 점수
- 활약 에피소드: 인물마다 4~5편, 모든 편에 `[영화/애니 작품명 + 연도]` 출처 배지
- 알고 있나요?: 인물마다 3개, 모달 상단 목차(프로필·관계·능력치·활약 에피소드·알고 있나요?)로 바로 이동
- 진영 색: 오토봇은 블루/레드, 디셉티콘은 퍼플/다크레드 액센트
- 설치: 삼성 인터넷 우측 상단 `⋮` → `홈 화면에 추가` (manifest + sw.js + 아이콘 180/192/512 + maskable)

## 구성

```
index.html                 앱 전체 (데이터·스타일·스크립트 포함)
assets/bots/{id}.webp      22명 실사 영화 모습 640×640 (오토봇 12 + 디셉티콘 10)
app-icon-180/192/512.png   앱 아이콘 (딥네이비 메탈릭 + 크림슨 엠블럼)
app-icon-maskable-*.png    마스커블 아이콘 (세이프존 여백 확보)
manifest.webmanifest       name: "트랜스포머"
sw.js                      오프라인 캐시 (transformers-dex-v11)
screenshots/               화면 캡처
```

## 배포

정적 파일만으로 동작합니다. `main` 브랜치 루트를 GitHub Pages(`Deploy from a branch` → `main` / `/ (root)`)로 지정하면 됩니다.
`.nojekyll`이 있어 Jekyll 처리를 건너뜁니다.

즐겨찾기 기록은 서버로 보내지 않고 그 기기의 브라우저 저장소에만 남습니다.
사진은 영화사·해즈브로가 공개한 공식 스틸·프로모 렌더 이미지를 비영리 어린이 팬 도감 용도로 쓴 것이며, 원본 파일은 Transformers Wiki(tfwiki.net)에서 받았습니다.
설정·연도·차량 정보는 Transformers Wiki(TFWiki)와 각 작품의 공식 설정을 참고했습니다.
